# Quora Clone

A basic Quora-inspired web application built using **Node.js, Express.js, EJS, HTML, CSS, and JavaScript**. The project implements CRUD operations, allowing users to create, view, edit, and delete posts.

## Features
- Create a new post
- View individual post
- Edit existing posts
- Delete posts
  
## Tech Stack
- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/quora-clone.git
   ```

2. Navigate to the project folder:
   ```bash
   cd quora-clone
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   node index.js
   ```

5. Open your browser and visit:
   ```
   http://localhost:8080
   ```
